Challenge

$500 → $10,000

Every entry gets logged with the callout, tweet, or announcement that triggered it. After ~30 trades this page tells you which sources actually make money — and which ones just feel exciting.

Read this before the first trade

  • $500 → $10,000 is a 20× return (+1,900%). That is not a stretch goal, it is an outlier outcome. Most accounts attempting it go to zero, because the leverage required to get there fast is the same leverage that liquidates you.
  • The goal is not a deadline. Nothing on this page has a date attached on purpose. A challenge with a clock forces bad size, and bad size is what actually ends challenges.
  • Only fund it with money you can lose entirely — not rent, not borrowed, not credit. If losing the $500 changes your month, the position size is already wrong.
  • Tweets and announcements are usually late. By the time a call is public, the move is often priced in and you are the exit liquidity. The source table below is how you find out whether that is happening to you specifically.
  • Nobody is trading this account but you. This tool records and grades decisions; it does not make them and it has no market access.
